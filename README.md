# 🐢 Turtle Race Game

A fun, interactive graphical turtle race built with Python's built-in **`turtle`** and **`random`** modules. This project is part of my **100 Days of Code: The Complete Python Pro Bootcamp** journey.

---

## 🎮 How It Works

1. **Place Your Bet:** When you run the script, a popup window prompts you to type in a color (e.g., `red`, `blue`, `green`, `orange`, `yellow`, or `purple`).
2. **The Race Begins:** Six colored turtles line up on the left side of the screen and race across to the right. Each turtle moves forward by a random step size in every loop iteration, making every race completely unpredictable!
3. **The Outcome:** The first turtle to cross the finish line wins. The console will print whether your predicted turtle won or lost.
